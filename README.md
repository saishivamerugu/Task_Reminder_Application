# Task Reminder Application

A simple and efficient **Task Reminder Application** built using **Java and Spring Boot** that helps users manage tasks and receive timely reminders.  
The application focuses on improving productivity by organizing tasks and notifying users before deadlines.

---

## 📌 Features

- Create, update, view, and delete tasks  
- Set due dates and reminder times  
- Automated task reminders  
- User-friendly and structured backend design  
- Secure and scalable architecture  

---

## 🛠️ Technologies Used

- **Java**
- **Spring Boot**
- **Spring MVC**
- **Spring Data JPA**
- **Hibernate**
- **MySQL**
- **Maven**
- **Postman** (for API testing)

---

## 🏗️ Project Architecture

- **Controller Layer** – Handles HTTP requests and responses  
- **Service Layer** – Contains business logic  
- **Repository Layer** – Manages database operations  
- **Entity Layer** – Represents database tables  

---

## ⚙️ Setup & Installation

1. Clone the repository:

   git clone https://github.com/saishivamerugu/Task_Reminder_Application.git


2. Open the project in **IntelliJ / Eclipse**

3. Configure **MySQL Database**:

   * Create a database
   * Update database credentials in `application.properties`

4. Run the application:

   
   mvn spring-boot:run
   

5. Test APIs using **Postman**
